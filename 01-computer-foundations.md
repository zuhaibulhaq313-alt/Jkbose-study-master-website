# Computer Foundations
## Basic concepts
A computer accepts data as input, processes it according to instructions, stores data/results and produces output. Hardware is the physical equipment; software is the programs and instructions.
- Input devices: keyboard, mouse, microphone, scanner.
- Output devices: monitor, printer, speakers.
- Storage: SSD, hard drive, memory card, optical media.
- CPU: executes instructions; commonly explained through control unit, arithmetic logic unit and registers.
- RAM is volatile working memory; storage retains data without power.

## Files and digital safety
A file stores information; a folder organises files. Use descriptive filenames and keep backup copies. Use strong unique passwords, enable two-factor authentication where available, avoid unknown attachments and never share OTPs or passwords.
Respect privacy and copyright. Ask permission before sharing another person's information or images.
