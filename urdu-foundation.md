# Urdu Foundation — General Study Guide
Use this as a language-learning support guide and match the exact lesson list to your prescribed JKBOSE Urdu textbook.
## Reading and vocabulary
- Read the lesson aloud in short sections.
- Maintain a vocabulary notebook: Urdu word, simple meaning, synonym/antonym if useful, and one sentence.
- Identify the main idea, speaker/characters, setting and message.
- For poetry, learn the central thought and explain difficult expressions in your own words.

## Grammar revision areas
Review noun/اسم, pronoun/ضمیر, verb/فعل, adjective/صفت, singular/plural, masculine/feminine where applicable, sentence construction, punctuation and common spelling patterns according to the prescribed syllabus.

## Answer-writing structure
1. Answer the exact question.
2. Add the supporting detail from the lesson.
3. Use clear, correct Urdu spelling.
4. For a summary, include only the main points and avoid unnecessary repetition.

## Practice
1. Write a short summary of a prescribed prose lesson.
2. Select ten difficult words and write their meanings.
3. Write five original sentences using new vocabulary.
4. Identify the main message of a poem prescribed by your teacher.
